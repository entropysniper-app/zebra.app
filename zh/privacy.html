Zebra · 隐私与数据

内容存在哪里，何时会离开设备。

这份说明介绍 Zebra 当前应用的数据处理方式，以及使用网页、邮件支持和公开问题反馈时需要了解的边界。

产品数据处理说明
说明核对日期：2026 年 11 月 3 日

默认保存在本机

笔记、标签、附件、设置和派生搜索索引保存在设备上的 Zebra 资料库；导出和备份保存到你选择的位置。Zebra 应用没有账号系统，不将笔记正文发送到开发者服务器。只有在你使用可选的外部智能体时，你选择的内容才会交给该智能体处理，见下文。

当前应用不包含广告、行为跟踪、产品分析或第三方崩溃上报服务。这一说明针对 Zebra 应用本身，不代替网站托管方、Apple 或你选择的第三方服务的数据说明。

本地搜索与转换

Mac 的语义搜索使用系统提供的中英文语言能力，在本机处理笔记和查询；Zebra 不为此下载模型或把正文发送到模型服务。设有密码的笔记即使已解锁，也不进入持久化语义索引。系统语义能力不可用时，关键词搜索仍可使用。

Mac 的文档转换在本机运行。确认导入后，转换后的笔记和保留的原件进入资料库；之后是否同步或分享，取决于你的设置和操作。iPhone 与 iPad 没有这套本地文档转换或语义搜索功能。

可选 iCloud 同步

新安装默认关闭 iCloud 同步，已有选择会保留。开启后，笔记正文、相关元数据和引用附件会进入你 Apple 账户的私有 CloudKit 数据库。设有密码的笔记以同样方式同步，Zebra 不会加密其内容。同步还会带上这些笔记的密码校验值和可选提示，但不包括密码本身。

Apple 提供 iCloud 服务，并按其条款和隐私政策处理服务数据。停用同步只停止当前设备，不会自动清除云端或其他设备上的副本。

笔记密码

设有密码的笔记只在 Zebra 界面中需要输入密码才能查看，Zebra 不加密其内容：标题、正文、标签和附件与其他笔记一样以明文保存在本机，开启同步后也以同样方式进入 iCloud。笔记锁定时，列表中只显示标题，也不参与搜索、维基链接建议和 Quick Look 预览。设有密码的笔记即使已解锁，也不进入 Spotlight、小组件和语义索引。

Zebra 不保存密码本身，只保存并同步由 PBKDF2-HMAC-SHA256 派生的密码校验值和可选的明文提示；取得资料库的人可以借此离线猜测密码，弱密码可能被猜中。所有设有密码的笔记共用一个密码，每台设备都用它解锁。在支持的 Mac 上，Touch ID 可以把密码只保存在这台 Mac 的钥匙串中，不同步到 iCloud 钥匙串；Zebra 不获取指纹或其他生物识别模板。

笔记密码用于防止旁人在 Zebra 中随手查看，不能防范能读取本机资料库、备份或 iCloud 数据的人或程序；添加密码也不会撤回此前已导出、分享、打印或备份的副本。开发者无法找回遗失的笔记密码。

网页、链接与主动分享

剪藏网页、从网址创建笔记、展示链接卡片或下载远程附件时，Zebra 可能直接请求相关网站。网站会收到正常连接所需的信息，例如请求的网址和 IP 地址。Safari 剪藏扩展在你调用剪藏时读取当前页面，再把选定内容交给 Zebra。

分享、导出、快捷指令或其他经你授权的操作，会把选择的内容交给相应应用或位置。接收方按照自己的设置和政策处理这些内容。

可选的外部智能体（Mac）

Mac 版的智能编辑、问 Zebra 和随 App 提供的 zebracli ai 可以连接 ACP（Agent Client Protocol）智能体。这项功能可选：智能体是你自己安装并登录的程序，Zebra 只在你使用这些功能时在本机启动它，不提供模型服务，也不经过开发者服务器转发内容。

首次向某个智能体发送前，Zebra 会说明将发送的内容和去向，并请你明确同意；你可以拒绝，普通编辑不受影响。同意后，Zebra 会发送你的提问或指令、所选文字及其前后各最多约 2000 字符的上下文（短笔记相当于全文）、检索到或你引用的笔记，以及你附加的图片；开启“允许智能体浏览整个资料库”时，智能体还可以按需列出、搜索和读取其他允许访问的笔记与附件。继续已保存的对话时，如果智能体无法恢复原会话，Zebra 还会把这段对话中较早的问答和图片发给当前智能体，即使它们当初是发给另一个智能体的；依据现已排除笔记得出的回答不会重发。设有密码的笔记（即使已解锁）、废纸篓中的笔记和带排除标签的笔记不会发送，归档笔记默认不发送。在终端运行 zebracli ai 时，发送前同样会说明去向，并需要你在终端确认、已在 Zebra 设置中同意且范围覆盖本次发送（CLI 默认允许智能体通过只读 MCP 检索资料库），或显式传入 --allow-data-sharing。

智能体通常会把内容交给它连接的第三方模型服务处理。这些内容如何保存、使用和删除，适用该智能体和模型服务各自的条款与隐私政策；开发者不接收这些内容，也无法控制第三方的处理。智能体是以你的账户在 Mac 上运行的独立程序：Zebra 的规则只约束它通过 Zebra 取得的笔记，不能阻止它用自身工具访问其他文件或网络。

授权对象是启动命令及其连接的模型服务，按智能体及其启动命令分别记录：在同一智能体内切换模型或模型服务不会再次询问；更换智能体、启动命令或环境变量，或者发送范围扩大（例如开启资料库浏览）时会再次询问。你可以在“设置 › 智能体”中随时撤销：撤销会停止 Zebra 中的连接，并对之后运行的 zebracli ai 生效，已在终端运行的对话需要在终端退出；撤销授权、给笔记设置密码或删除笔记，都不能撤回已经发送给智能体或模型服务的内容。

智能体会话记录

问 Zebra 的对话以明文保存在 Mac 上资料库旁的 AgentSessions.sqlite 文件中，包括消息、发送过的笔记内容快照、草稿、图片，以及待审修改和“还原”所需的附件副本。即使原笔记之后被删除或设置了密码，这些副本也会保留，直到你在会话历史中删除对应会话。

这个文件不进入 iCloud 同步，也不包含在 .zebrabk 资料库备份中；Time Machine 等整机备份可能会包含它。

保留与删除

你可以在 Zebra 中删除笔记和管理废纸篓。移除应用或停用同步，不会自动删除导出文件、备份、其他设备或云端已持有的内容。

删除笔记会更新当前状态，但云端同步历史中的旧记录及其引用的附件可能仍会保留。当前没有清除全部云端历史的按钮。删除或恢复重要资料前，请先保留独立备份。

本网站与问题反馈

本网站由 GitHub Pages 托管，不加载广告或产品分析脚本。GitHub 仍会处理提供网页所需的网络请求，可能包括 IP 地址、请求路径、时间和浏览器信息，其处理方式以 GitHub 的隐私声明为准。应用的本地保存不代表网站访问不会产生网络记录。

使用 GitHub 提交公开问题时，账号信息、文字和附件由 GitHub 处理，并可被其他人看到。我们通过这些信息回复和排查问题。请只提交所需的最少信息，不要上传私人笔记、密码、完整资料库或密钥。

通过邮件联系我们时，我们和邮件服务商 Gmail 会处理你的邮箱地址、消息及你主动发送的附件，用于回复和排查问题。请只发送必要的信息，不要发送密码或恢复密钥。
